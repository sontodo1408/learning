| 機能ID | 機能名 | 概要 | 優先度 | Phase |
|--------|--------|------|--------|-------|

### 2.2 機能詳細

#### F-001: Flashcard Mode

**概要**: 学習セットに含まれる用語カードを1枚ずつ表示する。カードをタップ/クリックすると表面（用語）から裏面（定義）へ反転し、前後のカードへ移動しながら暗記学習を行う。

**ユースケース**:
1. 利用者は学習セットの先頭カードの表面（用語）を確認する。
2. 利用者はカード本体、または専用の反転ボタンをタップ/クリックして裏面（定義）を表示する。
3. 利用者は「Prev」「Next」ボタンで前後のカードへ移動する。
4. 利用者は現在の学習進捗（現在カード番号 / 総カード数、達成率%）を確認する。
5. （デスクトップ）利用者はキーボードの Space / ↑ / ↓ キーでカードを反転できる。

**入力**:
- カードのタップ/クリック
- 反転ボタン、Prev/Next ボタンの操作
- （デスクトップのみ）キーボード操作（Space, ArrowUp, ArrowDown）

**出力**:
- カード表面（用語）/ 裏面（定義）の表示
- 進捗バー（幅は現在カード番号/総カード数に応じて変化）
- 進捗テキスト（例: "Card 1 / 20"、"5%"）
- 学習セットのコンテキスト表示（セット名、単元/科目タグ、難易度タグ）

**ビジネスルール**:
- カードは常に表面（用語）から表示を開始する。
- 進捗バーの幅は `現在カード番号 ÷ 総カード数` に基づいて動的に算出する。
- デスクトップは左サイドバー、モバイルはトップバー＋ボトムタブバーからモードを切り替える（F-004参照）。
- [要確認] モバイル版のみ、単元/科目タグと「⋮」（その他）メニューが表示される。デスクトップ版にも同等の要素を設けるか確認が必要。
- [要確認] カード反転アニメーションの回転軸がデスクトップ版（X軸: `rotateX`）とモバイル版（Y軸: `rotateY`）で異なる。どちらを正式仕様とするか、または意図的な差異かを確認する必要がある。

#### F-002: Learn Mode

**概要**: 用語の定義（または用語そのもの）を出題し、4択の選択肢から正解を選ぶ形式で学習を進める。学習は「ラウンド」単位で管理される。

**ユースケース**:
1. 利用者は出題カードに表示された定義文（タグ「Definition」付き）を読む。
2. 利用者は4つの選択肢の中から正しい用語を選択する。
3. 選択した選択肢は視覚的にハイライトされる。
4. （デスクトップ）利用者は「Don't know?」リンクを利用できる。
5. （モバイル）利用者は「Hint」「Report」ボタンを利用できる。
6. 利用者は現在の進捗（現在の設問番号 / 総設問数）とラウンド名を確認する。

**入力**:
- 選択肢のクリック/タップ
- 「Don't know?」（デスクトップ）/「Hint」「Report」（モバイル）ボタンの操作

**出力**:
- 出題カード（種別タグ「Definition」＋出題文）
- 4つの選択肢（選択状態のハイライト表示）
- 進捗バー・進捗テキスト（例: "4 / 25 Terms"）
- ラウンド名・学習セット名の表示（例: "Round 1: Initial Learning"）

**ビジネスルール**:
- 選択肢は常に4つ表示する。
- 選択済みの選択肢には枠線・背景色によるハイライトを適用する（既存選択の解除も可能）。
- 画面上部にラウンド名と対象学習セット名を表示する。
- [要確認] 「Don't know?」（デスクトップ）と「Hint」「Report」（モバイル）は提供内容が異なる。両OS間で機能を統一するか、意図的な差異かを確認する必要がある。
- [要確認] 誤答時・「わからない」選択時の挙動（正解表示、再出題タイミング等）はモックアップに明示されておらず確認が必要。

#### F-003: Test Mode

**概要**: 制限時間内に複数の設問（Multiple Choice、True/False 等）へ回答し、最後に一括で提出・採点するテスト形式の学習機能。

**ユースケース**:
1. 利用者はテスト名と残り時間（カウントダウンタイマー）を確認する。
2. 利用者は設問タイプ（Multiple Choice / True-False）に応じた回答UIで解答する。
3. 利用者は全設問への回答状況（設問番号 / 総設問数、完了率%）を確認する。
4. 利用者は「Submit Test」ボタンでテストを提出する。

**入力**:
- 選択肢（ラジオボタン）のクリック/タップ
- 「Submit Test」ボタンの操作

**出力**:
- テスト名、残り時間表示
- 設問カード（設問タイプタグ、配点、設問文、選択肢）
- 進捗バー・進捗テキスト（例: "Question 4 of 20"、"5% Completed"）
- 送信確認（Submit Test 実行後の挙動）

**ビジネスルール**:
- 各設問には設問タイプを示すタグ（例: "Multiple Choice", "True / False"）を表示する。
- （デスクトップ版）各設問に配点（例: "1 pt"）を表示する。
- タイマーはカウントダウン形式で残り時間を表示する。
- [要確認] 未回答の設問がある状態で「Submit Test」を実行した場合の挙動（警告表示の有無、提出可否）が未定義。
- [要確認] `test_mode_desktop_centered`（レスポンシブ内のモバイル表示）と `test_mode_mobile`（モバイル専用ファイル）は、タイマーの見た目（固定バー型 vs フローティングピル型）、選択肢UI（左側テキスト+ラジオ vs 右側チェックマーク）、カテゴリタグの有無など複数の点で異なるデザインとなっている。どちらを正式なモバイルUIとして採用するか確認が必要。

---

#### F-004: 共通ナビゲーション・モード切替

**概要**: Flashcards / Learn / Test の3モード間の切替、および画面幅に応じたレイアウト（デスクトップ／モバイル）の切替を行う、全モード共通のナビゲーション機能。

**ユースケース**:
1. 利用者はFlashcards / Learn / Testの各モードへ遷移する。
2. （デスクトップ）利用者は左サイドバーから「New Study Set」ボタン、Settings、Helpへアクセスする。
3. （モバイル）利用者はトップバーの通知・検索アイコン、ボトムタブバーの3モードアイコンを利用する。

**入力**:
- ナビゲーションリンク／アイコンのクリック・タップ

**出力**:
- アクティブなモードのハイライト表示（色、太字、アイコンFill状態）
- 画面幅に応じたレイアウト切替（サイドバー ⇔ トップ/ボトムバー）

**ビジネスルール**:
- 画面幅 `lg`（1024px）以上ではサイドバー形式、`lg` 未満ではトップバー＋ボトムタブバー形式のナビゲーションを採用する。
- アクティブなタブ/リンクは常に他のタブと視覚的に区別できる状態にする。
- [要確認] 「New Study Set」「Settings」「Help」「通知」「検索」の各遷移先画面は未モックアップのため、別途画面設計が必要。

## 3. 非機能要件

### 3.1 パフォーマンス要件
- カード反転・選択肢のホバー/選択などのUIアニメーションは、モックアップの実装値（0.2〜0.6秒、`cubic-bezier` イージング）を目安に滑らかに完了すること。
- [要確認] Tailwind CSS／Google Fonts／Material Symbols を外部CDNから読み込む構成のため、初回表示にはネットワーク接続が必須（現状オフライン非対応）。本番実装でのCDN依存継続の可否を確認する必要がある。

### 3.2 セキュリティ要件
- 現時点では静的モックアップであり、データの入出力を行わないため対象外。
- [要確認] 将来バックエンド接続時は `docs/00_Project_Guidelines/00_AI_Rules.md` のセキュリティ規律（機密情報の環境変数管理、入力検証等）に従うこと。

### 3.3 可用性要件
- レスポンシブデザインにより、`lg`（1024px）ブレークポイントを境にデスクトップ/モバイルレイアウトへ自動的に切り替わること。
- 主要な操作ボタンには `aria-label` を付与し、支援技術からの操作性を確保すること（現状 `test_mode_mobile` など一部画面のみ対応、全画面での統一が必要 [要確認]）。

### 3.4 保守性要件
- 全画面で共通のデザイントークン（`amber_study_system/DESIGN.md`）に基づいたTailwind設定（色・スペーシング・タイポグラフィ）を使用し、一貫性を保つこと。

## 6. 用語集

| 用語 | 定義 |
|------|------|
| Study Set | 学習対象の用語・定義・問題をまとめた1つの学習単位（例: "Biology 101: Cell Structure"） |
| Flashcard Mode | 用語カードを1枚ずつ表示し、タップ/クリックで反転させて暗記する学習モード |
| Learn Mode | 選択式の一問一答形式でラウンド単位に学習を進めるモード |
| Test Mode | 制限時間付きで複数の設問に回答し、まとめて採点するテストモード |
| Round | Learn Modeにおける学習の周回単位（例: "Round 1: Initial Learning"） |
