## 画面概要

### **基本情報**
- **画面ID**: SCR-01
- **画面名**: Flashcard Mode
- **URL**: `/study/:setId/flashcards`
- **モックアップ**: `flashcard_mode_desktop_centered/code.html`（PC）, `flashcard_mode_mobile/code.html`（モバイル）
- **対応デバイス**: PC / モバイル

### **目的・役割**
学習セットに含まれる用語カードを1枚ずつ表示し、タップ/クリックで表面（用語）と裏面（定義）を反転させながら暗記学習を行う画面。

### **Phase 1の実装範囲**
- カードの表示・反転（用語⇔定義）
- 前後のカードへの移動（Prev / Next）
- 学習進捗（現在カード番号 / 総カード数、達成率%）の表示
- 共通ナビゲーション（Flashcards / Learn / Test の切替）

### **Phase 2以降の予定**
- 学習セット作成・編集（"New Study Set"）
- 通知・検索機能
- [要確認] 習熟度に応じたカードの自動並べ替え・スキップ機能（モックアップ上は未実装）

```

### **全体構成（モバイル）**

```
┌───────────────────────────────┐
│ TopNavBar: Logo | 通知 検索      │  (固定, 上部)
├───────────────────────────────┤
│ 画面タイトル + タグ + [⋮]メニュー   │
├───────────────────────────────┤
│                                 │
│         Flashcard              │
│      （タップで反転）             │
│                                 │

│ [進捗バー]                       │

### **レスポンシブ対応**
- **PC（`lg`=1024px以上）**: 左サイドバー形式のナビゲーション、カードは画面中央に固定幅（最大400px相当）で表示。
- **モバイル（`lg`未満）**: 上部固定バー＋下部固定タブバー、カードは画面幅に応じて可変。
- [要確認] タブレット幅での挙動はモックアップ上未定義（PC/モバイルいずれかのレイアウトに寄せるか確認が必要）。

## 機能仕様

### **1. カード反転**

**動作**: カード本体またはFlipボタンをクリック/タップすると、表面⇔裏面が切り替わる

**トリガー**: カードクリック / Flipボタンクリック / （PC）キーボード操作

**処理フロー**:
1. 現在の反転状態を判定
2. 反転状態を反転（表→裏、裏→表）
3. アニメーションで表示を切替

**注**: 詳細な実装は `06_Detailed_Design/01_Flashcard_Mode_Detailed_Design.md` を参照

### **2. カード移動**

**動作**: Prev/Nextボタンをクリックすると、前後のカードに移動し、表面表示に戻る

**トリガー**: Prev / Next ボタンクリック

**処理フロー**:
1. 現在のカード番号を更新（-1 または +1）
2. カードの表示状態を表面にリセット
3. 進捗バー・進捗テキストを更新

**注**: 詳細な実装は `06_Detailed_Design/01_Flashcard_Mode_Detailed_Design.md` を参照
