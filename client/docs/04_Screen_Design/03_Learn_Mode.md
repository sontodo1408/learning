## 画面概要

### **基本情報**
- **画面ID**: SCR-02
- **画面名**: Learn Mode
- **URL**: `/study/:setId/learn`
- **モックアップ**: `learn_mode_desktop_centered/code.html`（PC）, `learn_mode_mobile/code.html`（モバイル）
- **対応デバイス**: PC / モバイル

### **目的・役割**
用語の定義を出題し、4択の選択肢から正しい用語を選ぶ形式で学習を進める画面。学習は「ラウンド」単位で管理される。

### **Phase 1の実装範囲**
- 出題カードの表示（定義文＋タグ）
- 4択選択肢の表示・選択・ハイライト
- ラウンド内の進捗（現在の設問番号 / 総設問数）表示
- 共通ナビゲーション（Flashcards / Learn / Test の切替）

### **Phase 2以降の予定**
- 正誤判定・フィードバック表示（モックアップ上は選択ハイライトのみで正誤表示は未実装）
- ラウンド完了後の結果画面・次ラウンドへの遷移
- [要確認] 「Don't know?」「Hint」「Report」の実際の動作仕様

## 機能仕様

### **1. 選択肢選択**

**動作**: 選択肢をクリック/タップすると、その選択肢がハイライトされ、他の選択肢のハイライトは解除される

**トリガー**: 選択肢ボタンのクリック/タップ

**処理フロー**:
1. 選択中の選択肢のハイライトを解除
2. クリックされた選択肢をハイライト
3. [要確認] 正誤判定・次の設問への遷移タイミングは未定義

**注**: 詳細な実装は `06_Detailed_Design/02_Learn_Mode_Detailed_Design.md` を参照

### **2. 進捗更新**

**動作**: 設問が進むごとに、進捗テキスト・進捗バーを更新する

**トリガー**: 設問遷移時

**処理フロー**:
1. 現在の設問番号を更新
2. 進捗バーの幅を再計算（現在設問番号 ÷ 総設問数）

**注**: 詳細な実装は `06_Detailed_Design/02_Learn_Mode_Detailed_Design.md` を参照
