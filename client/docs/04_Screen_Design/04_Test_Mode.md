## 画面概要

### **基本情報**
- **画面ID**: SCR-03
- **画面名**: Test Mode
- **URL**: `/study/:setId/test`
- **モックアップ**: `test_mode_desktop_centered/code.html`（PC/モバイル共通レスポンシブ実装）, `test_mode_mobile/code.html`（モバイル専用の別デザイン案 [要確認]）
- **対応デバイス**: PC / モバイル

### **目的・役割**
制限時間内に複数の設問（Multiple Choice、True/False）へ回答し、まとめて提出・採点するテスト形式の学習画面。

### **Phase 1の実装範囲**
- テスト名・残り時間（タイマー）の表示
- 設問カードの表示（設問タイプタグ、設問文、選択肢）
- 進捗表示（設問番号 / 総設問数、完了率%）
- テスト提出（Submit Test）
- 共通ナビゲーション（Flashcards / Learn / Test の切替）

### **Phase 2以降の予定**
- 採点結果・正誤フィードバック画面（モックアップ上は「送信」ボタンのみで、送信後の画面は未実装）
- タイマー0到達時の自動提出

### **レスポンシブ対応**
- **PC（`lg`=1024px以上）**: 左サイドバー形式、ヘッダー（テスト名・タイマー・進捗）はスクロール追従（sticky）。
- **モバイル（`lg`未満）**: 上部固定バー＋下部固定タブバー。
- **[要確認] 重大な不整合**: `test_mode_desktop_centered`（レスポンシブ実装内のモバイル表示）と `test_mode_mobile`（別ファイルのモバイル専用デザイン）は、タイマーの見た目、選択肢UIのスタイル、カテゴリタグの有無など、複数の点で異なるデザインになっている。実装前にどちらを正式なモバイルUIとするか、ステークホルダーの確認が必要。

## 機能仕様

### **1. 選択肢選択**

**動作**: 各設問の選択肢（ラジオボタン形式）をクリック/タップすると、その設問の回答として記録される

**トリガー**: 選択肢クリック/タップ

**処理フロー**:
1. 設問ごとに選択した回答を保持
2. 選択中の選択肢を視覚的にハイライト

**注**: 詳細な実装は `06_Detailed_Design/03_Test_Mode_Detailed_Design.md` を参照

### **2. タイマー表示**

**動作**: 画面表示中、残り時間をカウントダウン形式で表示し続ける

**トリガー**: 画面ロード時に開始

**処理フロー**:
1. 残り時間（初期値）を設定
2. 1秒ごとに残り時間を減算し、表示を更新
3. [要確認] 残り時間が0になった場合の挙動（自動提出等）は未定義

**注**: 詳細な実装は `06_Detailed_Design/03_Test_Mode_Detailed_Design.md` を参照

### **3. テスト提出**

**動作**: 「Submit Test」ボタンをクリック/タップすると、テストの回答を提出する

**トリガー**: Submit Test ボタンクリック

**処理フロー**:
1. [要確認] 未回答設問の有無をチェックするかどうか未定義
2. 回答データを送信
3. [要確認] 提出後の画面遷移（結果画面等）は未モックアップ

**注**: 詳細な実装は `06_Detailed_Design/03_Test_Mode_Detailed_Design.md` を参照
